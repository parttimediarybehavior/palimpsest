Palimpsest inspects revision groups, metadata, recoverable deletions, embedded objects, and image crops in Word documents, then selectively cleans supported categories entirely in the browser.

[Open the live app](https://parttimediarybehavior.github.io/palimpsest/) or download **palimpsest.html** below and open it directly. Eight examples are embedded. No account, API key, document upload, or runtime npm dependency is required. The source-code archives include the supplied corpus, fixtures, tests, build script, and attribution notes.

Publication verification:

- 88 synthetic assertions and 28 directed lineage comparisons passed.
- The scrub harness accepted its outputs for all 81 corpus documents and 115 parseable POI fixtures.
- Browser checks cover offline analysis, actual cleaned-document downloads and re-analysis, crop baking, embedded version comparison, malformed input, and mobile layout.

The publication review qualified unsupported authorship and timing conclusions, removed remote sample loading, and fixed narrow-screen report overflow. See `docs/PUBLICATION_REVIEW.md` for the scope. The supplied original project was preserved separately.

Metadata is mutable evidence, not proof of authorship, pasting, plagiarism, or labor. The cleaner's tests do not establish identical rendering in Microsoft Word or LibreOffice, or removal of every possible form of sensitive content. Review the selected removals and inspect the result.

Sample-document provenance and upstream notices are included. No new license has been assigned to the original project's source code.
