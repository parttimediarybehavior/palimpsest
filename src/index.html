Palimpsest
A Word document can retain traces of its editing history. Explore what is still inside.

Word can stamp edited text with a random w:rsid — a revision-save id — that remains in the saved file. Drop a .docx below to inspect revision groups, possible imported content, recorded editing-time metadata, recoverable deletions, and content outside image crops. Metadata is a clue, not proof of who wrote the text or how. Then choose the removals and download a cleaned copy with a before/after report.

what it finds

Revision groups. Document text coloured by its recorded revision id; these groups are not a complete writing timeline. Unlisted save-ids. Ids in the body but absent from its session list can suggest imported content or rewritten metadata. Editing-time arithmetic. Compare words with recorded minutes; resets, conversions, and missing metadata can affect the result. Recoverable content. Unaccepted tracked deletions, hidden/white/1-point text, comments, AutoText, embedded workbooks. Image excavation. Word keeps the whole picture and displays a window onto it, so the cropped-away part is still in the file — along with EXIF, GPS and camera model. Lineage. Drop a second version to see shared sessions and, via stable paragraph ids, exactly which paragraphs were silently rewritten.

and what it removes

Nineteen fixes, from rsid stamps and paragraph ids to tracked changes, comments, invisible runs, EXIF/GPS, sensitivity labels, AutoText, page thumbnails, UNC paths and language tags — plus baking image crops so the off-camera pixels stop travelling. The rewritten file is re-analyzed in front of you. The test harness checked 196 parsed documents for container consistency and visible-text preservation; a real Office renderer has not verified layout preservation. Inspect the cleaned copy before relying on it.
